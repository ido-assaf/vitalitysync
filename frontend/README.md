# VitalitySync frontend

React, React Router, Axios, and Socket.IO Client interface for VitalitySync.

See the root [`README.md`](../README.md) for complete project setup, API, WebSocket, AI, testing, and demonstration instructions.

Quick start:

```powershell
npm install
Copy-Item .env.example .env
npm start
```

Configure the backend with `REACT_APP_API_BASE_URL` and `REACT_APP_SOCKET_URL`.
